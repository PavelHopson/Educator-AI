# Production learning track v2

This first-party track teaches a single path: Vibe Coding with explicit boundaries, Spec Kit,
Harness Engineering, Safe Skills, and one production project. Completion requires evidence;
clicking through the UI is not enough.

The templates in `productionTrack.v2.mjs` are original Eclipse Forge checklists. They do not copy
closed course material or private prompts. Progress is designed for local versioned storage and
must never contain API keys, customer data, private repositories, or raw prompts from third parties.

The next UI slice should render one current module, its required evidence fields, a visible local-only
storage note, and a disabled completion action until every field is present.
